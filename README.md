# 🎬 Film / Dizi Öneri Sistemi

Python ve Flask kullanılarak geliştirilmiş modern bir film ve dizi öneri sistemidir.

## 🚀 Özellikler

- Film ve dizi arama
- TMDB API entegrasyonu
- Favori sistemi
- Tür bazlı öneri sistemi
- Modern ve responsive arayüz
- Türlere özel glow efektleri
- Dinamik öneri sistemi

## 🛠️ Kullanılan Teknolojiler

- Python
- Flask
- HTML5
- CSS3
- Jinja2
- TMDB API

## 📷 Proje Görselleri

Modern siyah ve kırmızı netflix vari bir tasarım ve türlere göre ayrı neon glow efektleri kullanılmıştır.

## ▶️ Kurulum

⭐Projeyi çalıştırmak için⭐:

```bash
pip install flask requests
```

Sonrasında:

```bash
python app.py
```
